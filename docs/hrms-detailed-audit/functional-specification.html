01. Purpose, scope and how to read this record

This document records the accessible portal's FEATURES AND BEHAVIOR. It is not a request to copy its visual design. The replacement will have its own design and must work on mobile, tablet and desktop.

The user has supplied all available access. HR/Admin access is unavailable and is deferred until after the employee-facing system is built. This record must remain useful without returning to the current portal. No further portal access is assumed by the proposed coverage or by the unresolved-items register.

Evidence labels used throughout: OBSERVED: screen, control, input attribute, state or interaction seen directly. CONFIRMED: behavior explicitly stated by the user. GUIDE: behavior described in the portal's built-in How It Works page; not proven by completing a live transaction. UNVERIFIED: exact behavior is not exposed by the accessible data or safe review. REQUIREMENT: user requirement for the replacement rather than a proven property of the current application.

The screenshots are evidence, not the design specification. The text snapshots preserve screen content; JSON snapshots preserve rendered control attributes, dropdown values and viewport measurements. Attributes such as required, min, max, accept and disabled are browser/UI evidence, not proof of server validation. DOM snapshots can include underlying navigation or background content while a dialog is open. This does not mean the background is interactable in that state.

Example balances, dates, counts, employee names and statuses reflect this review session. They must not become hardcoded values in the replacement. The evidence contains live account/company information; the functional text avoids repeating private employee contact details unnecessarily.

Draft form values were entered for inspection and reset or discarded. No leave, cancellation, registration, password reset email, correction, profile save, photo upload, asset change, payroll operation or attendance punch was submitted. A notification item was clicked to inspect its behavior; no navigation or clear visual state change was established. Read/unread persistence remains unverified.

Evidence: screenshots/ and evidence/ in this package; initial-reference/ contains the first walkthrough and explicit 390px, 768px and 1440px reference captures. This detailed record supersedes the initial checklist where they differ.
